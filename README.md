# Church Site App

Laravel and Vue application. The project's purpose and feature plan are still being defined.

## Development

- Start the Laravel development stack: `composer dev`
- Start only the frontend dev server: `npm run dev`
- Build frontend assets: `npm run build`
- Run PHP tests and checks: `composer test`
- Run the combined existing checks: `composer ci:check`

See `AGENTS.md` for the full command list.
